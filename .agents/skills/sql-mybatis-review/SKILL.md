# SQL MyBatis Review Skill

## 使用场景

当任务涉及 SQL、Mapper XML、MyBatis Plus、数据库表结构、索引、唯一约束、幂等表、交易表、结算表时使用本 Skill。

## 审查重点

1. 是否存在无 where 条件 update/delete。
2. 是否存在资金类操作缺少事务边界。
3. 是否存在幂等缺少唯一索引。
4. 是否存在状态更新缺少当前状态条件。
5. 是否存在软删除字段导致唯一索引失效或冲突。
6. 是否存在金额字段精度不足。
7. 是否存在币种字段缺失。
8. 是否存在交易号、商户订单号、渠道订单号缺少索引。
9. 是否存在高频查询缺少组合索引。
10. 是否存在 DO 字段和 SQL 字段不一致。
11. 是否存在 XML SQL 和 Java Mapper 命名不一致。
12. 是否存在生产初始化 SQL 中包含测试密钥或测试账号。

## 禁止行为

1. 不要直接修改生产 SQL。
2. 不要删除字段。
3. 不要改字段含义。
4. 不要随意改索引。
5. 不要把测试数据写入正式初始化脚本。

## 输出要求

输出：

1. 数据库风险；
2. Mapper 风险；
3. 幂等索引建议；
4. 查询索引建议；
5. 兼容性风险；
6. 回滚建议。
