# Test Regression Plan Skill

## 使用场景

当任务涉及代码修改后的测试计划、回归用例、验收清单、安全验证、异常场景验证时使用本 Skill。

## 测试范围

修改以下内容必须给出测试场景：

1. JWT 验签；
2. 请求体解密；
3. 响应 data 加密；
4. 防重放；
5. 商户身份校验；
6. IP 白名单；
7. 金额换算；
8. 币种精度；
9. 汇率计算；
10. 支付创建幂等；
11. 渠道回调幂等；
12. 状态流转；
13. 退款；
14. 代付；
15. MQ 重复消费；
16. 权限校验；
17. 敏感日志脱敏。

## 测试用例要求

每个测试点尽量包含：

1. 正常场景；
2. 参数异常；
3. 重复请求；
4. 状态不允许流转；
5. 边界金额；
6. 异常渠道响应；
7. 超时或重试；
8. 敏感字段脱敏检查。

## 输出格式

```text
测试模块：
测试目标：
前置条件：
测试场景：
预期结果：
风险点：
是否必须自动化：
```
