# Amount Currency Rate Review Skill

## 使用场景

当任务涉及金额、费率、汇率、币种、结算、清分、保证金、手续费、退款金额、最小单位金额时使用本 Skill。

## 审查重点

1. 是否使用 `BigDecimal` 处理金额、费率、汇率。
2. 是否出现 `double` / `float` 处理金额或汇率。
3. 是否默认所有币种都是 2 位小数。
4. 是否直接使用 `movePointRight(2)`。
5. 是否明确币种精度。
6. 是否明确舍入规则。
7. 是否区分交易金额、授权金额、请款金额、退款金额、手续费、保证金、结算金额。
8. 是否过早四舍五入。
9. 是否保留足够汇率精度。
10. 汇率是否区分交易汇率、结算汇率、查询展示汇率、清分汇率。
11. 多币种汇总是否按结算币种分组。
12. 授权类交易是否错误计入应结金额。

## 输出要求

输出：

1. 金额风险；
2. 币种精度风险；
3. 汇率风险；
4. 结算风险；
5. 建议修复方式；
6. 建议测试场景。
