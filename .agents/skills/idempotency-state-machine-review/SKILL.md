# Idempotency And State Machine Review Skill

## 使用场景

当任务涉及支付创建、代付创建、退款、渠道回调、商户通知、MQ 消费、交易状态、结算状态、对账入账时使用本 Skill。

## 审查重点

1. 是否有幂等维度。
2. 幂等是否有数据库唯一约束兜底。
3. 是否只依赖 Redis 做资金类最终幂等。
4. 状态流转是否有明确的可流转范围。
5. 终态是否不可逆。
6. 是否存在无条件覆盖状态。
7. 是否存在重复回调导致重复入账。
8. 是否存在 MQ 重复消费导致重复处理。
9. 是否存在先发 MQ 后提交事务。
10. 是否存在先通知商户后提交事务。
11. 是否区分平台交易状态和渠道原始状态。
12. 是否存在散落字符串状态。

## 支付系统必须保护的操作

1. 创建支付；
2. 授权；
3. 请款；
4. 预授权完成；
5. 撤销；
6. 冲正；
7. 退款；
8. 创建代付；
9. 代付审核；
10. 渠道回调；
11. 商户通知；
12. 对账入账；
13. 清分；
14. 结算；
15. MQ 消费。

## 输出要求

输出：

1. 幂等缺失点；
2. 状态机缺失点；
3. 资金风险；
4. 建议唯一索引；
5. 建议状态流转规则；
6. 建议测试场景。
