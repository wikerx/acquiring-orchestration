## 2. 治理原则

- 删除无业务信息的模板化 Javadoc，并禁止“工具类、业务类、处理相关业务、页面展示数据”等空泛描述。
- 补齐顶层 Java 类型、具有独立职责的 public static 嵌套类型、业务字段、枚举值、public/protected 方法和接口方法 Javadoc。
- 字段注释补充业务含义、单位/格式、敏感性、可空性、数据来源和字段关系。
- 方法注释补充职责、前置条件、参数来源、返回结果、状态变化、幂等/事务/外部调用/敏感数据边界。
- 核心 private 方法纳入扫描，覆盖支付鉴权、加解密、金额、状态机、幂等、MQ、渠道请求/响应、回调、商户通知等链路。
- 补充禁用模板检查，拦截“内部步骤”“请求参数或业务处理上下文”“当前模块泛化边界”等无效生成话术。
- 保留类职责、支付链路约束、安全边界、金额币种、幂等和状态机相关说明。
- 不通过注释改写业务语义，不修改接口字段、数据库字段、状态枚举和金额计算逻辑。
