# 完整支付链路日志设计

## 1. 链路事件

| 阶段 | 事件 |
|---|---|
| 交易受理 | `PAYMENT_TRANSACTION_START`、`PAYMENT_TRANSACTION_PREPARED`、`PAYMENT_TRANSACTION_END` |
| 后续交易 | `PAYMENT_FOLLOW_UP_START`、`PAYMENT_FOLLOW_UP_END` |
| 幂等锁 | `PAYMENT_IDEMPOTENCY_LOCK_BUSY` |
| 风控 | `PAYMENT_RISK_REQUEST_START`、`PAYMENT_RISK_REQUEST_END` |
| 路由 | `PAYMENT_ROUTE_START`、`PAYMENT_ROUTE_END`、`PAYMENT_ROUTE_NO_CANDIDATE`、`PAYMENT_ROUTE_MULTI_CANDIDATE` |
| 渠道调用 | `PAYMENT_CHANNEL_REQUEST_START`、`PAYMENT_CHANNEL_REQUEST_END`、`PAYMENT_CHANNEL_REQUEST_FAILED` |
| 渠道回调 | `OPENAPI_CHANNEL_CALLBACK_RECEIVE_START`、`OPENAPI_CHANNEL_CALLBACK_RECEIVE_END`、`PAYMENT_CHANNEL_CALLBACK_START`、`PAYMENT_CHANNEL_CALLBACK_END` |
| 回调状态推进 | `PAYMENT_CHANNEL_CALLBACK_STATUS_APPLY`、`PAYMENT_CHANNEL_CALLBACK_NON_TERMINAL`、`PAYMENT_CHANNEL_CALLBACK_STATUS_UNMAPPED` |
| 商户通知 | `PAYMENT_MERCHANT_NOTIFY_DUE_START`、`PAYMENT_MERCHANT_NOTIFY_ATTEMPT_START`、`PAYMENT_MERCHANT_NOTIFY_ATTEMPT_END` |
| 本地事件 | `PAYMENT_OUTBOX_SAVED`、`PAYMENT_CALLBACK_OUTBOX_SAVED` |

## 2. 字段约定

日志字段优先覆盖 `merchantId`、`merchantOrderNo`、`transactionId`、`operationId`、`transactionType`、`currency`、`amount`、`channelCode`、`requestId`、`callbackId`、`notifyId`、状态、耗时和处理结果。

禁止记录完整卡号、CVV、安全码、JWT、Authorization 头、私钥、API 密钥、商户密钥、完整原始报文和未脱敏异常堆栈。

## 3. 设计边界

本次日志建设只增加观测点和 trace 传播，不改变支付状态机、幂等键、金额换算、渠道响应映射、MQ 发布时机和数据库业务写入语义。
